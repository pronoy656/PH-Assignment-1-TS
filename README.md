# Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment focuses on solving programming problems using TypeScript and Object-Oriented Programming (OOP) concepts.

Throughout this assignment, I have implemented solutions covering the following TypeScript concepts:

- Functions and Optional Parameters
- Union Types and Type Narrowing
- Tuples and Readonly Properties
- Generics
- Interfaces and Array Methods
- Keyof and Indexed Access Types
- Classes, Inheritance, and Access Modifiers
- Promises and Asynchronous Programming

This repository contains my TypeScript assignment solutions and blog posts.
